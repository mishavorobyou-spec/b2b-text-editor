# B2B Editor — локальная версия 0.10

React, TypeScript, Ant Design 5 и Tiptap. Иконки из Figma сохранены в public/icons. Публикацию выполняем только после завершения редактора по указанию пользователя.

Контекст для продолжения работы: `INDEX.md`. Архитектура и роли файлов: `Карта_Проекта.md`.

## Запуск

`pnpm install`, затем `pnpm dev`. Локальный адрес: http://127.0.0.1:5173/. Сборка: `pnpm build`.

## Подключено

- Тип текста: Text и Heading 1–5. Изменяет текущий блок или выделенные блоки.
- Шрифт: Roboto, Times New Roman, Open Sans, Noto Sans, Rubik.
- Размер: 10, 12, 14, 16, 18, 20 px. Отображается также размер, унаследованный от заголовка.
- Шрифт и размер меняют выделение; при пустом выделении задают оформление последующего ввода.
- Full применяет выбор сразу. Short открывает окно с черновым выбором: Применить сохраняет, Отменить/Escape/клик снаружи сбрасывают черновик.
- Значения отражают оформление выделения и позиции курсора. Разные значения отображаются как «Смешанное».
- Жирный, курсивный, подчеркнутый и зачеркнутый текст работают с выделением и последующим вводом. Повторное нажатие снимает формат.
- Активное начертание отображается состоянием иконки из Figma; при наведении используется отдельное активное hover-состояние.
- Очистка форматирования удаляет с выделения все строчные стили, включая начертание, шрифт и размер, но сохраняет тип текстового блока.
- Нативное выделение мышью и клавиатурой оформлено светло-голубым цветом по макету и сохраняется при нажатии на кнопки начертания.
- Переключение Full/Short и размера иконок сохраняет документ. Disabled блокирует ввод и инструменты.
- Выравнивание работает по левому краю, по центру, по правому краю и по ширине; активный вариант отмечается в меню.
- Доступны нумерованные и маркированные списки. Повторный выбор снимает список, выбор другого типа переключает его.
- «Сместить вправо» и «Сместить влево» меняют уровень выбранного пункта списка. Смещение верхнего уровня влево не разрушает список.
- Межстрочное расстояние и расстояние между абзацами задаются в пикселях через окна с подтверждением. Отмена не меняет документ.
- Для обеих иконок интервалов доступны тултипы; маркеры списков занимают отдельную левую колонку.
- В layout Three эти команды находятся в окне «Дополнительные инструменты» и остаются функциональными.
- URL-ссылки можно сначала сохранить в общей локальной библиотеке, а затем применить к выделенному тексту. URL всегда открывается в новой вкладке.
- Инструмент «Якорь» вставляет именованный inline-тег в текущую позицию каретки. Тег можно переносить по документу за drag handle, переименовывать и удалять; повторный выбор существующего якоря перемещает его без дублирования. Сохранённый якорь можно выбрать в инструменте «Ссылка» и применить к выделению.
- Записи библиотеки можно искать, редактировать и удалять. Удаление якоря требует подтверждения: цель удаляется, а уже созданные переходы остаются в тексте и перестают работать.
- «Найти и заменить» подсвечивает совпадения, переключает активный результат, заменяет один или все результаты и поддерживает регистр, регулярные выражения и поиск без диакритики.
- Копирование, вырезание и вставка используют системный буфер обмена; отмена и повтор подключены к истории Tiptap.
- Инструмент «Таблица» создаёт таблицу из 1–10 колонок и 1–20 обычных строк. Опциональная строка заголовка добавляется сверху.
- Для выбранной ячейки доступны добавление строк и колонок с четырёх сторон, удаление строки/колонки, скрытие обводки и удаление таблицы. Выбранные соседние ячейки можно объединить, а объединённую — разделить. Ширина колонок меняется перетаскиванием границы; большая таблица прокручивается внутри редактора.

Text добавлен в оба варианта для возврата к обычному тексту. Для заголовков пока используются стандартные размеры Ant: 38/30/24/20/16 px; отдельные значения для них в предоставленном кейсе не заданы. Пользовательский размер текста сохраняется при смене типа блока. Web-шрифты, включая кириллицу, включены в сборку; Times New Roman использует системный шрифт с резервным serif.

## Границы этапа

Инструменты цвета, медиа, кода и специальных символов остаются демонстрацией. Теги страны, языка, валюты и переменной удалены из каталога. Оформленный документ живёт в экземпляре Tiptap до перезагрузки; долговременное сохранение пока не подключено. Общая библиотека ссылок и якорей сохраняется в localStorage браузера стенда.

## Интеграция

`Editor.tsx` экспортирует TextEditor и EditorToolbar. Использование:

```tsx
const [value, setValue] = useState('');
<TextEditor value={value} onChange={setValue} tools="Full" />
```

Совместимый value/onChange передаёт обычный текст. Внутри редактора хранится полноценный документ с разметкой; при интеграции сохранения нужно подключить JSON/HTML Tiptap, а не сохранять только value. Внешнее изменение value заменяет документ обычным текстом (сейчас используется для очистки).

Файлы: Editor.tsx, useTextDocument.ts, AnchorTag.tsx, TextFormatting.tsx, ToolPanels.tsx, их CSS, all-assets.ts, panel-assets.ts, public/icons. Подключения шрифтов и ConfigProvider находятся в main.tsx. Сам стенд и каталог не нужно переносить в целевой макет.

Варианты: layout One/Two/Three, density High/Short, tools Full/Short, iconSize 16/20. state фиксирует визуальное состояние; без state оно определяется автоматически. toolbarOnly скрывает поле.
