# B2B Editor — визуальная база

Отдельный стенд на React, TypeScript и Ant Design 5. Иконки экспортированы из предоставленного файла Figma и сохранены локально. Шрифт Inter включён в сборку.

## Запуск

`pnpm install` → `pnpm dev`. Сборка: `pnpm build`.

## Интеграция

Перенесите `src/Editor.tsx`, `src/editor.css`, `src/all-assets.ts` и `public/icons/`. Подключите Inter и ConfigProvider с токенами Ant Design из вашего приложения.

```tsx
const [value, setValue] = useState('');
<TextEditor value={value} onChange={setValue} layout="One" density="High" tools="Full" />
```

`EditorToolbar` экспортируется отдельно. `state` необязателен: без него состояния Default, Hover, Focused, Typing и Filled меняются от наведения, фокуса и ввода. Явный `state` фиксирует состояние для демонстрации; Disabled блокирует поле и панель. `toolbarOnly` скрывает поле.

Варианты: One — полная панель, Two — та же панель на ширине 768 px с переносом, Three — видимая часть панели с иконкой дополнительных инструментов. Full / Short меняют состав, High / Short — вертикальные отступы. Для Two используется High, как в макете.

Стенд позволяет вводить и очищать обычный текст. Кнопки форматирования, селекты панели и меню пока являются визуальными заготовками. Они не изменяют документ, не выполняют загрузки или операции с буфером обмена. Данные хранятся только в состоянии React до перезагрузки страницы.

Следующий этап — подключить движок форматирования к существующей панели; Input.TextArea заменить на область редактирования выбранного движка. Стенд и его настройки в целевой макет переносить не нужно.
