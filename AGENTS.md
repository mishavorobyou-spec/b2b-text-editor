# Контекст для продолжения работы

Перед изменениями прочитай `INDEX.md`. Затем открывай только нужные разделы из `Карта_Проекта.md` и исходные файлы, которых касается задача. `README.md` нужен для запуска, публичного API и известных ограничений.

Рабочие правила:

- Проект разрабатывается локально в этой папке. Не публиковать и не развёртывать его без прямой команды пользователя.
- Макеты и состояния сверять с указанными пользователем узлами Figma. Иконки сохранять локально в `public/icons`.
- «Абзацы и структура» пока не развивать.
- После функционального изменения проверить TypeScript, production-сборку и затронутый пользовательский сценарий в браузере.
- После завершённого этапа обновить в `INDEX.md` состояние, сделанное, ограничения и следующий шаг. `Карта_Проекта.md` менять только при изменении структуры или потока данных.
- Не копировать в документы длинные листинги кода и перечни всех иконок: ссылки на исходные файлы служат источником деталей.
